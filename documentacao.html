Registro automatico de alteracoes em produtos

O sistema registra mudancas feitas na tabela produtos na tabela historico_alteracoes por meio da trigger trg_produto_update, sem depender de codigo de log na aplicacao.

Tabelas

Tabela Colunas principais Funcao
produtos id (PK), nome, descricao, preco, quantidade Cadastro dos itens e saldos atuais.
historico_alteracoes id (PK), id_produto (FK), data_alteracao, campo_alterado, valor_antigo, valor_novo Log de cada coluna modificada apos um UPDATE.

Como a trigger atua

A trigger e AFTER UPDATE ON produtos FOR EACH ROW. Cada coluna (nome, descricao, preco e quantidade) e comparada com <=>: se NOT (OLD.campo <=> NEW.campo), uma linha e inserida em historico_alteracoes. Usar <=> evita falha quando um campo passa de NULL para um texto ou vice-versa, e quando mais de uma coluna muda no mesmo comando, cada coluna gera seu proprio registro.

Definicao da trigger

CREATE TRIGGER trg_produto_update
AFTER UPDATE ON produtos
FOR EACH ROW
BEGIN
  IF NOT (OLD.nome <=> NEW.nome) THEN
    INSERT INTO historico_alteracoes (id_produto, data_alteracao, campo_alterado, valor_antigo, valor_novo)
    VALUES (NEW.id, NOW(), 'nome', OLD.nome, NEW.nome);
  END IF;

  IF NOT (OLD.descricao <=> NEW.descricao) THEN
    INSERT INTO historico_alteracoes (id_produto, data_alteracao, campo_alterado, valor_antigo, valor_novo)
    VALUES (NEW.id, NOW(), 'descricao', OLD.descricao, NEW.descricao);
  END IF;

  IF NOT (OLD.preco <=> NEW.preco) THEN
    INSERT INTO historico_alteracoes (id_produto, data_alteracao, campo_alterado, valor_antigo, valor_novo)
    VALUES (NEW.id, NOW(), 'preco', OLD.preco, NEW.preco);
  END IF;

  IF NOT (OLD.quantidade <=> NEW.quantidade) THEN
    INSERT INTO historico_alteracoes (id_produto, data_alteracao, campo_alterado, valor_antigo, valor_novo)
    VALUES (NEW.id, NOW(), 'quantidade', OLD.quantidade, NEW.quantidade);
  END IF;
END;

Teste rapido

Na tela principal, edite o preco ou a quantidade de um produto e salve. A linha nova aparece na tabela de historico com o valor anterior e o valor atual.
